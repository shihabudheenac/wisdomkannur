# Wisdom Islamic Organisation — Kannur District Committee

A responsive coming-soon landing page built with Next.js App Router.

## Stack

- Next.js 16.2.11
- React 19.2
- TypeScript
- CSS only for styling and decorative geometry

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

The project uses Next.js 16.2.11, an Active LTS release at the time of creation, rather than an older vulnerable Next.js version.
